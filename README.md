# Simon Says

A memory game where you repeat an growing sequence of colors and sounds. Each round adds one more step. How far can you go?

**[Play it live](https://akash-kumar-maurya.github.io/simon-says/)**

## How to Play

1. Press **Start** to begin.
2. Watch the sequence of flashing colors.
3. Repeat the sequence by clicking the buttons in the same order.
4. Each round adds one more step. One wrong move ends the game.

## Features

- Increasing difficulty with every round
- Score and high score tracking
- Works on desktop and mobile

## Run Locally

```bash
git clone https://github.com/YOUR-USERNAME/simon-says.git
cd simon-says
```

Then open `index.html` in your browser.

*(If your project uses Node, replace the last step with `npm install` and `npm start`.)*
